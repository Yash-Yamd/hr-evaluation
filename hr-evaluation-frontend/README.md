# 人事評価管理システム：画面側

ReactとViteを使った、評価入力画面・評価一覧と結果画面です。

**アプリ全体の概要、準備、MySQLとSpring Bootの起動、操作方法、計算ルールは [全体のREADME](../README.md) を参照してください。**

## このフォルダで使うコマンド

初回、または必要なライブラリを揃え直す場合：

```powershell
npm ci
```

開発用の画面を起動する場合：

```powershell
npm run dev -- --host 127.0.0.1
```

配布用の画面ファイルを作る場合：

```powershell
npm run build
```

画面から `/api` への通信は、開発用サーバーが `http://127.0.0.1:8080` のSpring Bootへ転送します。画面だけで保存・計算は完結しません。

ビルドで作成される `dist` の公開方法は未設定です。ビルド成功は、アプリ全体を公開できたことを意味しません。
